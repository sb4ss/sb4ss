Estoy desarrollando **Tukicode** para trabajar con IA desde la terminal. Puede leer los archivos del proyecto, usar herramientas y ejecutar comandos. Está hecho en **Python**, con un motor en **Rust** para tareas como buscar código y manejar archivos.

### Cómo se usa

- **Chat:** para preguntar algo, revisar código o hacer un cambio puntual.
- **Plan:** propone los pasos y espera tu aprobación antes de ejecutarlos.
- **Build:** prepara el plan y empieza a ejecutarlo.

### Algunas cosas que ya tiene

- Funciona con **Ollama, OpenRouter, Gemini y Anthropic**.
- Puede ejecutar **varias herramientas en paralelo**.
- Tiene una interfaz de terminal con **chat, explorador de archivos y consola**.
- Soporta comandos en segundo plano, compresión del contexto y **prompt caching**.
- Se puede usar en **Windows, macOS y Linux**.
