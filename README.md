**Tukicode** es un agente de programación CLI de código abierto que ayuda a ejecutar tareas de desarrollo desde la terminal. Combina una arquitectura asíncrona en **Python** con un motor nativo en **Rust** para operaciones de archivos, búsqueda de código y terminal.

### Tres modos, según lo que necesitas

- **Chat:** preguntas, explicaciones y arreglos puntuales.
- **Plan:** revisa un plan antes de ejecutar tareas de varios pasos.
- **Build:** ejecuta el plan para construir proyectos de forma autónoma.

### Lo que hay bajo el capó

- **IA local o en la nube:** Ollama, OpenRouter, Gemini y Anthropic.
- **Herramientas en paralelo:** ejecución asíncrona y procesamiento simultáneo.
- **Una terminal completa:** TUI con chat, explorador de archivos y consola; soporte de PTY y procesos en segundo plano.
- **Contexto y planificación:** compresión de memoria, prompt caching y planes estructurados.
- **Multiplataforma:** Windows, macOS y Linux.

> Me interesa acercar la IA al trabajo real de desarrollo: comprender el proyecto, planear y ejecutar con herramientas, desde el mismo lugar donde programamos.
